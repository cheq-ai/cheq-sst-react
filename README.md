# Getting Started
This project can be run on **Android**, **iOS**, or **Web** for testing across different devices.

## Prerequisites
- Node.js (LTS recommended)
- npm

## Install Dependencies

```bash
npm install
```

## Run the App
Run **one** of the following commands depending on the platform you want to test:

### Android
```bash
npm run start:android
```

### iOS
```bash
npm run start:ios
```

### Web
```bash
npm run start:web
```

## Configuration
You can customize the app configuration by editing the following file:

```
source/cheq-sst-react/src/Sst.ts
```

Changes made there will be picked up the next time you run the app.
